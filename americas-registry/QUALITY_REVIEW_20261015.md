# アメリカ地域台帳：品質改善レビュー（2026-10-15）

## 改善した点

従来の `audit.py` は軽量な集計・計画生成として残し、厳密な定期実行用の入口を `quality_cycle.py` に追加した。地名レコードの追加や自動収集ではなく、既存データを安全に利用・拡張するための更新である。

### 1. 検索時にもデータの内容を確認する

`north-america-registry/query.py` は、保存済みマニフェストに対するindex・anchors・選択した地域CSVのSHA-256、CSVの列数、空欄、重複ID、原典コード、親ID、国・州の所属、候補フラグ、実行数を検査する。壊れた行は黙って無視せず、検索結果を返す前にエラーにする。manifestの完全性フラグが空の場合も拒否する。

JSONの重複キー・非有限値、不正な型、パスの逸脱、シンボリックリンクを拒否する。検索用には引用符・ハイフン・アクセントを正規化するが、返却する原典名・ID・言語は変更しない。未収録地域に対する `candidate-only` は、無視せずエラーにする。

**検証範囲は選択したファイルである。** ハッシュ整合性は、第三者による署名、原典内容の真実性、現時点の最新性や配送可能性を保証しない。US/CA/MX/BR原本の全ファイル・親子関係検査は既存の `scripts/verify_americas_snapshots.py` も併用する。

### 2. 国別の不一致を大陸合計で隠さない

新しいループは57国・地域の正確なM49所属を確認する。中米・カリブ海・南米では国別metadata.jsonの固定ハッシュと、地名件数・行政区画件数・候補件数・未解決親IDなど8指標をcoverage.csvと照合する。国同士の件数が入れ替わって大陸合計だけ一致するケースも失敗にする。

公式US/CA/MXレイヤーについては、保存ファイルのチェックサムと既存の全行・親子関係検査まで実行する。南米のBRはGeoNamesとして扱い、別のIBGE台帳を二重加算しない。

**地域別GeoNames圧縮ペイロード本体の再展開・全行再検証は、この新ループでは実行しない。** レポートに `regional_gazetteer_payload_checks=not_run` を記録する。地域固有のbuild/verify・materialize検査は引き続き別途必要である。

### 3. 失敗を記録して、北から順に繰り返す

```bash
python americas-registry/quality_cycle.py --rounds 2 --state-file /tmp/americas-state.json
python americas-registry/quality_cycle.py --area northern-america --rounds 2 --state-file /tmp/northern-state.json
python -m unittest discover -s tests -p 'test_americas_*.py' -v
```

順序は北部アメリカ→中米→カリブ海→南米で固定する。一地域が失敗しても残りを検査し、全体は失敗終了する。失敗地域の件数をゼロに置き換えず、全体件数はnullとする。

状態ファイルには検証した入力ファイルのハッシュ、成功・失敗、前回からの変更、復旧状態を残す。保存は一時ファイルからの置換で行い、途中の保存失敗で以前の状態を壊さない。元データのディレクトリへの状態ファイル出力は禁止する。

前回と同じ入力でも毎回検証し直す。変化がないと `no_validated_input_change` で停止する。実行回数には最後の変化なし確認も含める。これはバックグラウンド収集や無限の強化学習ではなく、最大20回の有限な監査である。入力ハッシュの対象外にある地域圧縮ペイロードや、外部サイトの更新は検知しない。

### 4. 行政区画名シードと日付を厳密に扱う

行政区画名シードには地名・種類・国の重複、出典の不足、不適切な発行者ホスト、配送検証済みへの誤昇格を拒否する検査を追加した。PMのINSEEコードは単に97501/97502のどちらかであればよいとせず、名称とコードの対応まで確認する。

[出典レビュー](../north-america-registry/evidence-review.json)では、INSEE資料の公開年月、地理的基準日、人口の基準日、適用開始日を分離した。2026年からの適用だから2026年の行政区画データである、という推論はしない。今回のPDF確認は抽出テキストに基づき、画像取得は失敗したことも記録した。全シードの原典を今回再検証したわけではない。

### 5. テストと証跡を保存する

既存12テストに39テストを追加した。実データを一時コピーして改変し、ハッシュを更新した場合にも構造的な誤りを拒否することを検査する。CIは既存原本保護テストも実行し、結果・国別レポート・ハッシュを成功失敗にかかわらず14日間のartifactとして保存する。Actionsは確認したコミットSHAに固定し、リポジトリ書き込み権限を付与しない。

## 変えていないもの・残る課題

公式スナップショット、地名CSV、既存の18行政区画シード、第三者のライセンスは変更していない。今回追加した地名レコードは0件。国・地域の出典レイヤーは52/57のままである。

次に必要なのは、BM・GL・PMの集落レベル原典収集、CR・CUの掲載範囲の確認、言語別名称の原典照合、郵便番号との多対多対応、街路・番地・建物・部屋の別レイヤー整備である。行政区画名のシードをこの完了件数に数えない。
