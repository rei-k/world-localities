# アジア住所・地名の事前学習計画

2026-10-01作成。**計画段階で、モデル学習・強化学習・精度改善の実証は未実行です。**
サービス投入前の学習は可能です。まず検索・制約による基準を作り、教師あり学習で候補選択を改善し、
強化学習は「検索・追加確認・確定・保留」の判断に使います。基盤モデルをゼロから作る事前学習とは区別します。
欧州で強化学習が実行済みであることは、このリポジトリからは確認できていません。

## 学習対象

| 優先 | 処理 | 最初の方法 |
|---|---|---|
| 1 | 地名・別名・表記の揺れから地域ID候補を検索 | 正規化検索、対照学習、小型ランキング |
| 1 | 同名地域を国・所属・対象種別で識別 | 教師ありランキング |
| 2 | 所属・時点・番号の矛盾を見つける | 原典に基づく制約検査 |
| 2 | 確定・追加確認・保留を選ぶ | 校正した閾値、必要なら行動方策の強化学習 |
| 3 | 現地語・国内英語・国際英語の名称を選ぶ | 出典付き辞書と用途条件 |
| 3 | 郵便番号から許容される地域集合を絞る | 公式の多対多対応と候補ランキング |
| 3 | 住所を分解し、正しい順に表示する | 分解器と国別テンプレート |
| 4 | 地図との整合 | 別途境界資料を整備して空間照合 |

言語で地域IDを入れ替えず、同じIDの名称を選びます。住所全体を単純に逆順にしません。
公式名称と番号の更新は辞書更新で反映し、すべてを学習し直す構成は避けます。
ローマ字は共通アルゴリズムと原典例外で扱い、変換できる処理を学習モデルに覚え込ませる必要はありません。

## 現在使える根拠と不足

基礎版は52プロファイル、3,277,921行、ADM1〜ADM5は209,753行。
直接親が未解決の134,732行、国の範囲だけの7,903行、ADM1がないlocalityの42,710行は、
確認済み所属として補完しません。これらの品質指標は重複するため合算しません。
GeoNamesの別名は原典内の対応で、全件の言語・公式性・同一性は確認済みではありません。
異なる `gn:` IDを無条件に別の実在地域とする強い負例も作りません。

[JP・TWの公式対応](../regions/asia/official/README.md) を追加しました。
日本の公式コード・郵便関係・カナと、台湾の原典内の中英対照・3桁接頭辞が初期の根拠になります。
日本の未一致・複数候補・文字数上限到達の可能性があるローマ字、GeoNames照合候補は、確認済み正解から除外します。
日本のローマ字を英語の正解に、台湾の3桁を完全6桁の正解にしません。
原典の公開日・観測日と実際の適用期間を区別し、独立に確認した評価例を別に用意します。

## 小規模な比較実験

候補はJP・KR・TW・SG・IN。各2,000対象、各対象最大4合成例を上限案とし、
独立確認した評価問い合わせを各200例確保することを目標にします。まだ学習例・評価正解を作成した件数ではありません。

1. B0：検索・既知の制約・保留。
2. B1：同じ候補集合を使う教師ありランキング。
3. B2：必要な場合のみ、操作例による言語モデルのSFT。
4. R1：検索、根拠確認、追加質問、ID確定、保留を選ぶ方策の強化学習。

一度の候補選択だけなら、ランキングや文脈付きバンディットで十分かを先に比較します。
RLの観測には入力・候補・取得済み根拠・残りの操作回数を与え、正解ID・採点用ラベルは漏らしません。
固定した資料と応答で再現可能な環境を作り、根拠のないID・公式性の断定は出力制約でも拒否します。

初期報酬案は、根拠付き正解+1、情報不足での正当な保留+0.2、不必要な保留-0.2、誤ID-2、
架空のID・出典や未確認の公式断定-3、追加操作1回-0.02、上限3回です。
数値は最適値ではなく検証集合で調整する案です。全問保留も比較し、長い説明や流暢さでは加点しません。
採点は独立の正解と検証可能な関係を中心にし、モデルの自己評価だけにしません。

## 分割・評価・採用条件

ID、確認済み同一実体、別名を同じグループにして分割し、その後で表記の揺れを生成します。
欧州とのAM/AZ/CY/GE/RU/TRなどの重複は `gn:` IDで除去します。
別の行政区域・空間ブロック、将来版、少数言語・同名・旧名・欠損・国指定誤りを別の評価群にします。
検索台帳に評価対象IDがあることと、評価問い合わせ・正解を重みの学習に使うことは区別します。
合成変換が他の実在地名や曖昧な名前になったら一意な正解を強制しません。
ラベル欠損だけで「本来回答不能」と判断しません。

候補検索Recall@kと候補内選択精度を別々に測り、ID一致率、誤確定率、回答率、
郵便候補集合の一致、追加質問数、処理時間、国別平均を示します。
RLは、独立評価でB1/B2と同じ回答率で誤確定が減る、または同じ誤確定率で回答率・操作数が改善した場合に採用します。
信頼区間、乱数種、国・難例群ごとの悪化も確認します。住所の配達可能性の保証には使いません。
