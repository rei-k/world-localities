# 世界250地域の監査と小分け更新

第1回は、対象範囲・不足状況・今後の反映順を登録する。
地域別の実装と大容量データは、後続の更新で個別に扱う。

監査の基準日は2026-10-18。対象は当時のUN M49公表248地域と、技術上の追加範囲TW・XKの計250地域。
250は主権国家数ではない。BV・HM・AQ・海外領も含む。

## 今回追加するもの

| ファイル | 内容 |
| --- | --- |
| `20261018/coverage.csv` | 全250地域の追加原典件数・未完了状態・次の作業 |
| `20261018/summary.json` | 対象範囲、集計値、原ファイルのSHA-256、網羅性の限界 |
| `20261018/verification.json` | この小分け更新で実行した整合性検査 |
| `updates.json` | 地域別・海外領・公式住所取込を分けた反映順 |

## 完了条件を分ける

| 項目 | 必要な照合 |
| --- | --- |
| 行政区 | 基準日付き公式台帳の全階層・原典ID・親参照 |
| 住所用の通り | 名称のある通りや住所用地区の公式台帳 |
| 物理的な道路網 | 無名・未採番の道路を含む独立した道路台帳 |
| 割当番地 | 元の番号・接尾辞・状態を保持した割当記録 |

全250地域で4項目とも完全性が未確認のため、未完了タスクは1,000件。
分母不明の収録率と独立台帳件数は空欄とし、0%や100%へ変換しない。
配達可能性は今回の対象外。建物・部屋の自動入力も対象に含めない。

## 件数の意味

CSVの `new_` 列と `physical_road_records_added` は、今回の公式住所追加版で得た観測数。
従来からの全データ件数ではない。0は、その地域に行政区・道路・番地が存在しないという意味ではない。
国・地域コードは文字列として読み、ナミビアの `NA` を欠損値へ変換しない。

住所観測30,517,925行には全国版と海外地域版の重複や履歴が含まれる。
一意な家屋数ではない。住所の追加がある地域は14、今回新たに加えた物理的な道路網は0件。
過去の住所取得記録だけがある地域も、元データと独立台帳の照合が終わるまで完了へ昇格しない。
空のBAN配布3件も要確認として残す。

今回は監査表と保存済みリリース集計の整合性を確認した。
地域別索引・原典30,869,030行の再照合や、以前の1,064件の統合テストを
今回の監査表追加時に再実行したという意味ではない。

後続の更新は `updates.json` の順で、対象ごとに検証し、独立したコミットで反映する。
