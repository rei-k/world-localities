# 郵便当局の中国語・英語対照と3桁郵便区域

中華郵政の「縣市鄉鎮中英對照檔」371行について、中国語 `zh-Hant`、英語 `en`、
3桁郵便区域コードを同じIDへ接続しました。対訳と番号は原典の同じ行にあり、類似名の推測で結合していません。

対照371組、名称742行、郵便関連371行、3桁コード368種類です。
`300` は3区域、`600` は2区域に関係し、一つの区域へ潰しません。
`postal_links.csv` はすべて `code_kind=prefix`。完全6桁番号の対応は未収録です。
原典に国内英語と国際英語の用途差がないため `audience=unspecified` としています。

出典：[政府資料開放平臺 資料5949](https://data.gov.tw/dataset/5949)、提供機関：中華郵政股份有限公司。
[原本XML](https://www.post.gov.tw/post/download/County_h_10906.xml)を2026-10-01に取得。
[公式ダウンロード一覧](https://www.post.gov.tw/post/internet/Download/index.jsp?ID=220306)のXML掲載日は2020-06-12です。
取得日を2026年時点の名称の現行性保証とはしません。元ファイルとSHA-256を保持しています。

`tw-postal-area:` は原典の完全な中国語区域名から作る派生IDで、公式行政コードではありません。
言語・郵便番号の切り替えでは同じIDですが、改称の同一性は別途履歴照合が必要です。
島嶼等を含む原典の郵便サービス上の見方を保持し、行政上の親子関係・実効支配は推定しません。
GeoNamesとの公式対応、番地・配達可能性の確認は未収録です。
