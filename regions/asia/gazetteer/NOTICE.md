# Data attribution

Source: GeoNames geographical database, https://www.geonames.org/

Country extracts and source documentation:
https://download.geonames.org/export/dump/
https://download.geonames.org/export/dump/readme.txt

GeoNames data is provided under Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

WorldAddress modifications: selected populated-place features and ADM1–ADM5,
historical ADM1–ADM5 and ADMD features; retained the 19 original source columns;
added namespaced IDs, conservative administrative-code relationships, quality
flags, CSV serialization, deterministic compression, manifests and validation reports.
Country/area codes and alternative country codes remain source assertions.
No endorsement by GeoNames or a government/postal authority is implied.

See manifest.json and country metadata.json for original download URLs,
retrieval timestamps, source Last-Modified values and SHA-256 checksums.
The original source is community-maintained; independent verification of all
names, legal status, municipality completeness and current administrative boundaries
has not been performed. These files contain no verified delivery address database.

Retain this attribution when redistributing the source-derived data. Code licensing
is separate and is described in address-foundation/LICENSE.
