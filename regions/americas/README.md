# 米州

UN M49の地理区分に沿う4フォルダにまとめました。`northern` / `southern` は短いフォルダ名で、分類名はそれぞれ Northern America / South America です。

- [northern](northern/README.md)：Northern America (021)。US・CAの公式snapshot
- [central](central/README.md)：Central America (013)。6か国のGeoNames、別にMX公式snapshot
- [caribbean](caribbean/README.md)：Caribbean (029)。27か国・地域のGeoNames
- [southern](southern/README.md)：South America (005)。14か国・地域のGeoNames、別にBR公式snapshot
- [公式snapshotの共通説明・出典](official/README.md)

北部のGeoNamesパッケージ、中央のCR/MX GeoNames、カリブのCU、南米のAR/PYは未収録です。
MX公式snapshotは収録済みです。USの原典に含まれるPuerto RicoはUSパッケージ内に残し、カリブのPR GeoNamesとは別レイヤーとして扱います。
完全網羅・現在の法的自治体台帳とは主張しません。重複する原典間の件数は合算しません。
