# 地域別データ

同じ地域の基礎地名は `gazetteer/`、独立した公式資料は `official/` に配置します。

- [アフリカ](africa/gazetteer/README.md)
- アジア：[基礎地名](asia/gazetteer/README.md) / [公式名称・郵便関連](asia/official/README.md)
- ヨーロッパ：[基礎地名](europe/gazetteer/README.md) / [公式LAU](europe/official/README.md)
- [オセアニア](oceania/gazetteer/README.md)
- [米州](americas/README.md)

収録範囲と未収録国は [ルートREADME](../README.md)、全パッケージのパスと国コードは [catalog.json](../catalog.json) にあります。
スキーマとIDを統一したものではありません。オセアニアの元パック内部にあるGeoNames・名称・公式AU資料も、それぞれの出典とIDを維持します。
